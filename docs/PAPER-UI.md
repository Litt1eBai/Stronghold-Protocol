# 纸鸢界面与官方 0.3.0 的同步

以官方 0.3.0 的玩法、数据与插件实现为基础，选择性移植
[Paper-Yuan/Stronghold-Protocol 的 0.2.6 分支](https://github.com/Paper-Yuan/Stronghold-Protocol/tree/d0d2023dede3981b71886600f41c15402e64be4a)
（`d0d2023dede3981b71886600f41c15402e64be4a`）的客户端体验。

## 同步范围

- 大厅的中央标志、邀请与公开同盟入口、协议选择场景和过渡动画。
- 夜巡、霜原、烬野、静默四种背景，以及本机自定义图片；图片缩放后放入 IndexedDB，偏好放入
  localStorage，不上传到服务器。清除浏览器数据会删除图片及偏好。
- S.W.E.E.P. 的盟约、策略和敌方资料，以及从盟约报告进入干员调配。
- 房间的四席立绘卡片、名片干员选择、邀请和 AI 按钮。`room.card` 只同步表现，不进入对局输入。
- 卡片式干员调配、装备图鉴、列表切换、技能/模组/潜能练度/皮肤快捷编辑。自选干员沿用官方选择规则，
  换装按实际干员 ID 保存，不随自选槽位继承。素材地址读取当前安装的清单，支持内容哈希 URL。
- 同盟文字聊天、可拖动浮窗和按钮、弹幕开关。聊天在房间内临时保存最近 80 条，每条至多 200 个字符，
  每个会话间隔至少 1 秒；观战者可聊天，房间之外的人不能读取。退出房间清空本机显示，房间销毁后记录消失。
- 统一设置内的 3D 地图亮度和冷暖调整（默认 100%），只改变地图材质；原有单位、特效与性能设置继续使用。

保留本仓库账号注册、密码登录、会话恢复与已有账号数据库。大厅的个人信息入口读取现有账号。
原有 Android 签名、包内更新、统一原生设置和 CNB 发布部署设施继续兼容。
Android 壳补上系统文件选择器回调，用于背景图片和配置导入；只回传用户选择的 `content:` 文档 URI，
取消或关闭页面时清理回调，不申请存储权限。APK 内的文件选择支持需安装本次重新构建的客户端。

## 官方规则与插件兼容

不引入无限火力、装备无限发放、十人房间、跨服大厅或纸鸢的随机玩法。服务器仍按官方 0.3.0
处理人数上限、卡池、装备库存、回合、技能和插件内容集。没有实现的自动匹配入口保持隐藏。

房间保留插件标签、玩法模式名称、逐席内容校验状态、可信脚本同意流程，以及准备/开始前的校验门槛。
战斗 HUD、作战统计和特效实现继续使用官方 0.3.0；未移植依赖纸鸢旧版战斗组件的样式。皮肤仅改变表现，默认与现有测试场景的战斗结果应完全一致；
本次不更新 golden 文件。

3D 官方场景依赖主机已有的本地提取素材；没有场景素材时继续使用原版金属棋盘。本次未向 Git 引入游戏美术。
